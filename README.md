# 击掌评论互动原型

一个可直接在浏览器中运行的移动端社区互动原型，演示普通评论转换为「击掌评论」、长按操作、右滑击掌、公开回应和私信击掌。

## 运行

在项目根目录启动静态文件服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。页面无需构建步骤或运行时依赖。

## 演示

1. 点击页面上方「重置」，恢复初始共享数据。
2. 在小林视角长按一条普通评论，打开第二张独立卡片中的「击掌评论」开关。
3. 切换到阿青视角，向右滑动该评论并在提示「松手击掌」时松手；桌面端也可长按评论，在操作面板中选择「击掌」。
4. 切回小林视角，从评论下方查看参与者并选择「回应大家」，或从「赞和收藏」打开击掌私信。

5. 阿青击掌后可点击「已击掌 · X人」取消，也可长按选择「取消击掌」；再次击掌只计数一次。
6. 小林关闭击掌时，从未有人参与的评论恢复普通评论；已有记录显示「X人曾击掌」。取消不删除已收到的提醒、公开回复和私信。

评论长按面板保留独立操作分组，输入区域统一使用文本框和图标工具栏。右滑未达到 88px 时松手回退；达到后在原头像位置碰撞并回弹，动画层独立于评论裁切范围。系统减少动态效果时直接呈现成功状态。

角色共用浏览器本地模拟数据；「重置」会恢复双方的初始演示状态。所有互动均为前端模拟，不会连接真实消息服务。

## 项目文件

- `index.html`：原型页面入口
- `app.js`：页面渲染、角色切换及互动模拟
- `style.css`：移动端界面与击掌动效
- `xhs-icons.js`：页面图标
- `assets/`：笔记图片及角色头像
